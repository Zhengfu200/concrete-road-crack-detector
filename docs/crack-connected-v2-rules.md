# 裂缝整体标注规则：connected-v2.0

状态：50张训练集试标待用户确认；未冻结，未发布全量数据。日期：2026-10-25。

类别只有 `0: crack`。一个实例是一组在当前画面内**可见且可确认连通**的裂缝；Y、T、十字分叉的连通网络为一个实例。框为该整体可见范围的紧致轴对齐外接矩形，不人为加宽。

| 情况 | 处理 |
|---|---|
| 同一条连续裂缝分成多个原多边形 | 按原图确认连通后合为一个整体框 |
| 分叉/交叉处清晰连通 | 所有连通支路合为一个框 |
| 独立、平行裂缝，或只存在外接框重叠 | 分别标框，不能仅因距离或框重叠而合并 |
| 多边形有小缺口但原图裂缝明显连续 | 可合并，记录图像依据 |
| 遮挡/间断不能确认连接，或不能区分裂缝与接缝 | 整张待定，注明原因；不得充当背景 |
| 伸出画面的裂缝 | 框到图像内可见端点 |
| 漏标裂缝 | 补框，并记录原多边形为空或遗漏 |
| 接缝、切割线、污渍、阴影 | 排除，记录对应多边形与理由 |

先在训练集50张不同文件名前缀家族试标：连续拆段20、分叉交叉10、独立多裂缝10、细弱5、贴边/遮挡5。文件名前缀仅用于避免增强重复，不代表已核实独立拍摄来源。

首轮隐藏模型预测。AI提出的改标、用户逐图确认、混凝土材质/来源审核分别记录。逐图确认只确认本规则下的框，不代表材质或独立来源已通过验收。

试标逐张确认完成后，用户在复核页面“确认试标并冻结规则”。规则摘要或试标标注摘要变化即使冻结失效。之后才开启剩余图片复核，保持原train/val/test身份；不照搬增强图坐标。

每张记录原图和原标签SHA-256、原多边形到新实例的对应、排除原因、补框/修正原因、复核者类型、时间、修订历史。待定图不导出；未复核图不导出，数量和原因进入发布清单。

发布路径 `data/prepared/crack-connected-v2`，不得覆盖已存在版本。原图、源多边形、V1导出、历史模型/报告保留。只有全量逐张已有复核或待定结论、数据检查合格，才能发布可训练V2。50张试标不作为训练版本。全量AI逐图复核记录为 `agent_reviewed`，用户确认记录为 `confirmed`；草稿不能导出，发布清单分别统计复核者类型，不能将AI复核写作人工复核。

旧模型和新模型在同一冻结V2验证集重新建立基线；不能把与V1指标的变化当作模型学习提升。参考评估只允许val，报告/阈值必须独立，不改变旧模型验收状态。
