## 评估

```powershell
python evaluate.py --weights runs/concrete-crack-v10s/weights/best.pt --data data/prepared/crack-seg-user-20261021 --split val --calibrate
python evaluate.py --weights runs/concrete-crack-v10s/weights/best.pt --data data/prepared/crack-seg-user-20261021 --split test
```

只在验证集选择一个裂缝阈值，使用每个实际预测分数构成的完整曲线（同分数预测作为一组），检查Recall≥90%、Precision≥80%的联合目标。存在可行阈值时优先提高召回；不存在时明确记录 `joint_target_feasible=false`，最大F1阈值仅用于未验收预览，不代表达标。阈值文件还记录Precision≥80%时的最高Recall以及Recall≥90%时的最高Precision。测试输出裂缝Precision、Recall、mAP50、mAP50-95、2×2的“裂缝/背景”混淆矩阵和错误示例，并检查裂缝和无裂缝场景；实际是否达标以独立测试为准。

阈值、类别和权重摘要保存在权重旁的 `.thresholds.json`、`.release.json`，复制模型时一同复制。正式检测入口要求精度验收通过；开发预览可明确加 `--allow-unvalidated`，画面显示未验收标记。

评估与视频检测共用 `preprocessing.py`：保持图片比例，将长边缩放至 `--imgsz`，居中填充为同尺寸方图，再四周各加16像素灰边（BGR 114）。因此 `--imgsz 960` 表示内容区域960×960，实际模型输入992×992；预测框统一还原并裁剪至原图，完全落在填充区的框不作为图像检测结果。`imgsz` 必须是正的32倍数。此规则适用于宽屏、竖屏和方图。

评估从0.001置信度收集一次共用路径预测；固定阈值的P/R、混淆矩阵及mAP均使用这份预测。mAP沿用Ultralytics的IoU匹配和AP算法，不再单独调用 `model.val()` 走另一套图像处理。训练期间Ultralytics的验证逻辑未修改，训练日志指标应与本项目部署评估分别记录。

新阈值和评估报告记录 `preprocessing` 版本及参数。旧版本阈值必须在验证集重新校准，不能直接用于新流程正式评估。未验收预览遇到旧阈值会提示并使用0.20开发阈值，仍显示未验收；旧验收说明不能自动沿用到新预处理。历史权重和报告不会因代码更新自动重写。需要保留旧阈值时，用 `--thresholds` 为新校准指定独立文件，同时用 `--output` 指定新的报告目录。

### 可选重复框抑制候选

`--nms-iou 0.3` 在YOLOv10s原生检测后增加按类别的贪心重复框抑制，默认关闭；此时应称为“YOLOv10s + NMS后处理”候选，不能宣称整条流程无NMS。评估、视频与摄像头共用此选项，阈值文件绑定对应的 `letterbox-border-nms-v1` 协议。显式传入不匹配的 `--thresholds` 文件会报错，避免把无NMS阈值直接用于NMS候选。

2026-10-24在原模型验证集上比较了0.3～0.8的六个IoU值，以Recall@Precision≥80%为主、F1为次选择0.3；这是验证集开发搜索，尚无独立场景验收证据。其单独验证报告及阈值在 `reports/concrete-crack-20261021-212347/duplicate-suppression-20261024`。

```powershell
python detect.py --weights runs/concrete-crack-20261021-212347/weights/best.pt --nms-iou 0.3 --thresholds reports/concrete-crack-20261021-212347/duplicate-suppression-20261024/val.thresholds.json --allow-unvalidated
```

该命令仍显示未验收水印。新的微调候选应在相同后处理条件下另行比较，不能因为训练完成就自动替换推荐模型。

本轮完整对照见 `reports/model-improvement-20261024/summary.md`，预览配置保存在 `configs/preview-improved.json`。可双击 `05_优化候选预览_未验收.cmd`，或运行 `python preview_improved.py`。默认按Precision≥80%下的最高召回点预览；推荐阈值单独保存，原权重旁的阈值不改写。当前推荐原权重加IoU=0.3重复框抑制，验证集该点P=80.16%、R=79.52%，仍未达联合验收要求。预测对置信度采用包含边界的 `score >= threshold`，与完整曲线校准一致。

最多20轮微调因连续6轮验证未改善，在第10轮提前停止；候选未优于原模型，保留作对照，未替换原权重。完整200张验证图像已通过推荐阈值下评估/实际Detector输出一致性核对，记录在同目录 `runtime-verification.json`。所有结果均属验证集开发结果，没有新的独立测试验收结论。

## 错误复核与困难样本小规模对照（2026-10-24）

`reports/hard-example-review-20261024/review-report.md` 及两个 `visual-review.csv` 保存48张验证错误图、48张训练困难图的逐张Codex视觉观察，包含原图/叠加图图册。该记录不是独立人工的混凝土材质、拍摄来源或最终验收。保留原分割多边形外接框的检测单位，不将整体/局部框差异直接当成标签错误。实际改标0张；V24空标签但有可见裂缝、T39弱竖线等单独列为待处理问题。

`review_hard_examples.py` 仅在现有train挖掘困难样本；`record_visual_review.py` 保存本次已查看图册的观察记录。抽取34张避免重复文件名前缀增强的困难图，另选606张训练图，生成独立版本 `data/prepared/crack-seg-hardreview-20261024`。同640张图用于两组训练，val/test图片和标签与原版本逐文件核对字节一致，正式默认数据入口保持原版本。

`run_review_ablation.py` 运行两个单种子3轮先导实验：均匀权重和困难图3倍权重。每轮均有放回抽取640次；学习率1e-5、固定BN运行统计及其他设置两组相同，只比较采样权重。采样器和数据指纹在各run的 `sampling-configuration.json` 记录。

对照结果见 `reports/review-ablation-20261024/comparison.md`：两组R@P80均为75.10%，低于原候选79.52%。因此没有替换 `configs/preview-improved.json` 和原推荐权重；保留全部试验结果。单种子小样本结果不能作为最终泛化或验收结论。

新增了对训练结束回调的保护：Ultralytics的final_eval会使用epoch+1再触发一次回调，该事件不算新的训练轮次，也不参与部署候选选择。本轮历史记录中的该回调另存为排除项，实际每组均训练3轮。
