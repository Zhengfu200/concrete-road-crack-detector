# 固定模型和阈值运行道路视频

日期：2026-10-29。这个入口只负责按冻结参数检测、保存结果和来源记录，不自动完成精度验收。本次尚未收到新视频路径，功能检查使用之前已观察的适配视频30帧，不当作新的独立验收。

## 使用方法

1. 在本机程序目录双击 `08_固定模型阈值_道路视频检测.cmd`。
2. 在选择窗口中选择要检测的道路视频。运行时无阈值滑块，也不读取可能随以后优化而改变的05/07预览配置。
3. 等待控制台显示“检测完成”。处理的是所选视频全部可解码帧；只有开发人员显式加 `--max-frames` 才会截断，并在运行记录中注明。
4. 输出位于 `outputs/frozen-road-20261029/本次唯一目录/`。`detections.mp4`为无音轨带框视频；`run.json`记录输入路径、输入SHA-256、模型与阈值摘要、环境及运行状态；`contract.json`保存本次冻结配置；`frames.csv`与`frames.json`记录逐帧计数和性能概要。原视频保留。

## 正式精度验收还需要什么

- 使用没有参与训练、调参和模型选择的新拍摄视频。之前那段微信视频已经用于诊断，继续运行只能作为开发复查；同一旧视频再截一段也不能直接当新独立来源。
- 验收前固定取样范围、抽帧方案、原始画面/ROI以及标注规则。保持连通整体裂缝一个实例、独立裂缝分开；包括正常背景、裂缝、阴影及模糊等实际场景，不按检测结果挑选或排除。
- 对原始帧建立人工真实标注；标注时不参考模型预测框。仅有带框视频无法计算真实Precision和Recall。
- 固定模型和本阈值后，对冻结的验收标注计算框匹配IoU≥0.5的Precision/Recall，目标P≥80%、R≥90%，并核查场景覆盖、材质与来源独立性。NMS0.3与评估匹配IoU0.5用途不同。
- 若根据这段视频修改模型、阈值或裁剪，它就参与了开发，需另留没有参与这些选择的新来源用于最终验收。单一短片的结果仅支持其覆盖的场景，不自动说明所有道路都达到同样精度。
